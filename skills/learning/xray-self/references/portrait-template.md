# xray-self portrait template

默认用于“决策画像”。五层扫描必须完成，但正文只保留改变判断的证据。用户明确要完整画像时，可增加至多两组独立的“结论 → 证据 → 能力圈/缺口 → 行动”，不要复制整套章节。

## 模板

```md
---
tags:
  - xray-self
  - 自画像
created: YYYY-MM-DD
updated: YYYY-MM-DD
source: "vault-wide scan"
---

# {最影响下一步的判断，写进标题}

> 默认动作：{现在应做什么。}
> 会改变它的条件：{什么新事实会让默认动作失效。}

## 结论

| 判断 | 置信度 | 决定性证据 | 可推翻条件 |
|---|---|---|---|
| | 确定 / 较确定 / 推测 | 最多 3 条，标路径或扫描依据 | |

## 证据

| 扫描层 | 保留的事实 | 它如何改变判断 |
|---|---|---|
| 统计 / 加工 / 拓扑 / 痕迹 / 时间中的相关层 | | |

## 能力圈与缺口

- **可调用的能力**：{证据 → 它能帮助完成什么行动。}
- **关键缺口**：{证据 → 它正在阻碍什么。}
- **边界**：{该能力不能替代什么，避免把优势当万能解释。}

## 刺痛

{一句不处理这个缺口的具体代价。必须由两条独立证据支撑；不要重复结论。}

## 下一步

1. **{行动}**：{验收标准。建议期限：YYYY-MM-DD 或下一次复盘前。}
2. **{可选的第二行动}**：{验收标准。}
```
